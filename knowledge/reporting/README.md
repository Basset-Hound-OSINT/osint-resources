## Key Principles

### BLUF (Bottom Line Up Front)
Every report leads with the key finding. Decision-makers see the most important information first.

### Confidence Language
Standard terms ensure consistent communication:
- **Almost certainly** (95%+)
- **Very likely** (80-95%)
- **Likely** (60-80%)
- **Roughly even chance** (40-60%)
- **Unlikely** (20-40%)
- **Very unlikely** (5-20%)
- **Almost certainly not** (<5%)

### Sourcing Requirements
All factual claims require source citations with reliability assessments using the standard 6x6 system (A-F reliability, 1-6 validity).

### Sensitivity Markings
OSINT-specific markings for handling:
- **OSINT-UNRESTRICTED**: Public information, no restrictions
- **OSINT-SENSITIVE**: Personal information, internal only
- **OSINT-RESTRICTED**: Source/method protection, limited distribution

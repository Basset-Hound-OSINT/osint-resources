# Organization Profile Template

This template provides a structured format for documenting OSINT findings about organizations, companies, groups, or entities. It covers organizational structure, operations, digital infrastructure, and public presence.

**Reference Sources**: Criminal Intelligence for Analysts, Joint Analysis Handbook, TII Online Research Framework, Intelligence Analysis Reports

---

## Profile Header

```
===============================================================================
                       ORGANIZATION PROFILE
===============================================================================

PROFILE NUMBER:     [YYYY-MM-DD-ORG-###]
DATE CREATED:       [Initial creation date]
LAST UPDATED:       [Most recent update]
CLASSIFICATION:     [OSINT / OSINT-SENSITIVE / OSINT-RESTRICTED]

ORGANIZATION NAME:  [Primary/Legal name]
ALSO KNOWN AS:      [Alternative names, abbreviations, translations]

ORGANIZATION TYPE:  [Corporation / NGO / Government / Informal Group / etc.]
STATUS:             [Active / Inactive / Dissolved / Monitoring]
PRIORITY:           [High / Medium / Low]

PREPARED BY:        [Analyst name/identifier]
CASE REFERENCE:     [Related case number if applicable]

===============================================================================
```

## Template Checklist

Before finalizing your profile, verify:

- [ ] Basic organization information is documented
- [ ] Key leadership is identified
- [ ] Organizational structure is described
- [ ] Core operations are documented
- [ ] Digital infrastructure is mapped
- [ ] Public presence and reputation assessed
- [ ] Key findings are clearly stated with confidence levels
- [ ] Timeline captures significant events
- [ ] Related entities are cross-referenced
- [ ] Evidence is properly logged
- [ ] Information gaps are identified
- [ ] Sensitivity markings are appropriate

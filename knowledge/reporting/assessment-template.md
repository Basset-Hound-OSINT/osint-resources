# Assessment Template

This template provides a structured format for intelligence assessments, emphasizing analytical rigor, confidence levels, and clear communication of judgments versus facts.

**Reference Sources**: ICD-203 (Analytic Standards), ODNI Style Manual (2011-2013), Tradecraft Primer for Structured Analytic Techniques, Psychology of Intelligence Analysis

---

## Assessment Header

```
===============================================================================
                         INTELLIGENCE ASSESSMENT
===============================================================================

ASSESSMENT NUMBER:  [YYYY-MM-DD-A###]
DATE:               [Date of assessment]
CLASSIFICATION:     [OSINT / OSINT-SENSITIVE / OSINT-RESTRICTED]

TITLE:              [Descriptive title of the assessment]
SUBJECT:            [Entity, situation, or issue being assessed]

PREPARED BY:        [Analyst name/identifier]
COORDINATED WITH:   [Other analysts or teams if applicable]

ASSESSMENT TYPE:    [Predictive / Explanatory / Evaluative / Estimative]

===============================================================================
```

## Key Judgments

```
KEY JUDGMENTS
-------------

1. [First key judgment - most important]

   Confidence: [HIGH / MODERATE / LOW]

   Rationale: [2-3 sentences explaining why this confidence level]

2. [Second key judgment]

   Confidence: [HIGH / MODERATE / LOW]

   Rationale: [Brief explanation]

3. [Third key judgment]

   Confidence: [HIGH / MODERATE / LOW]

   Rationale: [Brief explanation]
```

## Confidence Levels and Probability Language

### Standard Confidence Levels

| Level | Definition | Criteria |
|-------|------------|----------|
| **HIGH** | Based on high-quality information and/or the nature of the issue makes it possible to render a solid judgment | Multiple corroborating sources; direct evidence; well-established patterns |
| **MODERATE** | Based on credibly sourced and plausible information, but not of sufficient quality or corroboration to warrant high confidence | Some corroboration; indirect evidence; less established patterns |
| **LOW** | Based on questionable or implausible information, or information too fragmented or poorly corroborated to make solid analytic inferences | Limited sources; circumstantial evidence; significant gaps |

### Probability Language

Use these terms consistently throughout the assessment:

| Term | Probability Range | When to Use |
|------|-------------------|-------------|
| **Almost certainly** | 95%+ | Virtual certainty based on compelling evidence |
| **Very likely** | 80-95% | High probability with strong supporting evidence |
| **Likely** | 60-80% | More probable than not with good evidence |
| **Roughly even chance** | 40-60% | Could go either way; evidence is balanced |
| **Unlikely** | 20-40% | Less probable than not |
| **Very unlikely** | 5-20% | Low probability but not impossible |
| **Almost certainly not** | <5% | Near certainty of non-occurrence |

### Probability vs. Confidence

```
IMPORTANT DISTINCTION
---------------------

Probability: How likely something is to be true or to occur
Confidence: How certain we are in our assessment

Example:
"We assess with HIGH CONFIDENCE that Subject X will LIKELY attempt to
expand operations in the next 6 months."

- HIGH CONFIDENCE: We have strong evidence for this judgment
- LIKELY (60-80%): The probability of occurrence is more likely than not,
  but not near-certain
```

## Analytic Judgments vs. Facts

Clearly distinguish between what is known and what is assessed.

```
FACTS (What We Know)
--------------------

1. [Verified fact with source citation]
   Source: [Specific source reference]

2. [Verified fact with source citation]
   Source: [Specific source reference]

3. [Verified fact with source citation]
   Source: [Specific source reference]

JUDGMENTS (What We Assess)
--------------------------

1. [Analytical judgment with confidence level]

   Supporting Evidence:
   - [Evidence point 1]
   - [Evidence point 2]

   Logic/Reasoning:
   [Explain the analytical reasoning connecting evidence to judgment]

2. [Additional judgment with confidence level]

   Supporting Evidence:
   - [Evidence point 1]
   - [Evidence point 2]

   Logic/Reasoning:
   [Explain reasoning]
```

-----------

## Alternative Analysis

Present alternative hypotheses or interpretations that were considered.

```
ALTERNATIVE ANALYSIS
--------------------

Alternative Hypothesis 1: [State the alternative view]
--------------------------------------------------------------------------------

Description:
[Explain this alternative interpretation of the evidence]

Evidence Supporting This View:
- [Evidence point 1]
- [Evidence point 2]

Evidence Against This View:
- [Counter-evidence point 1]
- [Counter-evidence point 2]

Why We Rejected/Weighted Lower:
[Explain why the primary judgment was preferred over this alternative]

Probability: [Assign probability to this alternative]

Alternative Hypothesis 2: [State another alternative view]
--------------------------------------------------------------------------------

[Follow same structure as above]

DEVIL'S ADVOCATE CONSIDERATION
------------------------------

[Present the strongest possible case against the primary judgment. This
forces rigorous examination of assumptions and evidence.]

What would need to be true for our primary judgment to be wrong?
- [Condition 1]
- [Condition 2]
- [Condition 3]

Indicators that would suggest we are wrong:
- [Indicator 1 to monitor]
- [Indicator 2 to monitor]
```

## Linchpin Analysis

Identify the critical factors upon which the assessment depends.

```
LINCHPIN ANALYSIS
-----------------

Linchpins are the critical assumptions or pieces of evidence that the
assessment depends upon most heavily.

Linchpin 1: [Critical assumption or evidence]
- Why it matters: [Explain significance]
- Confidence in linchpin: [HIGH / MODERATE / LOW]
- If this changes: [How would assessment change]

Linchpin 2: [Critical assumption or evidence]
- Why it matters: [Explain significance]
- Confidence in linchpin: [HIGH / MODERATE / LOW]
- If this changes: [How would assessment change]

MONITORING INDICATORS
---------------------

Track these indicators for changes that could affect the assessment:

1. [Indicator to monitor] - Current status: [Describe]
2. [Indicator to monitor] - Current status: [Describe]
3. [Indicator to monitor] - Current status: [Describe]
```

## Assessment Checklist

Before finalizing your assessment, verify:

- [ ] Intelligence question is clearly stated
- [ ] Key judgments use explicit confidence levels
- [ ] Probability language is used consistently
- [ ] Facts and judgments are clearly distinguished
- [ ] All assumptions are stated with impact analysis
- [ ] Alternative hypotheses are meaningfully analyzed
- [ ] Linchpins are identified
- [ ] Sources are documented with reliability ratings
- [ ] Implications are addressed
- [ ] Indicators for monitoring are specified

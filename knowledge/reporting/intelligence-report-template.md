# Intelligence Report Template

This template follows intelligence community standards for structured reporting, adapted for Open Source Intelligence (OSINT) practitioners.

**Reference Sources**: CIA Writing Guide (2017), DIA Style Manual for Intelligence Products (2016), ODNI Style Manual (2011-2013), Army Intelligence Center of Excellence Writing Guide (2022)

---

## Report Header

```
===============================================================================
                         INTELLIGENCE REPORT
===============================================================================

REPORT NUMBER:      [YYYY-MM-DD-###]
DATE:               [Date of report]
CLASSIFICATION:     [OSINT / OSINT-SENSITIVE / OSINT-RESTRICTED]
HANDLING:           [Distribution restrictions if any]

SUBJECT:            [Clear, specific subject line]

PREPARED BY:        [Analyst name/identifier]
REVIEWED BY:        [Reviewer if applicable]

===============================================================================
```

---

## BLUF (Bottom Line Up Front)

**Purpose**: The BLUF is the most critical element of an intelligence report. It states the key finding or assessment in 2-4 sentences at the very beginning.

```
BOTTOM LINE UP FRONT
--------------------

[State the primary finding or assessment clearly and concisely. This should
answer the "so what?" question immediately. Include the most significant
implications if space permits.]

Example:
"Subject JOHN DOE almost certainly operates multiple social media accounts
under false identities to promote disinformation narratives. Analysis of
posting patterns, linguistic markers, and network connections indicates
coordination with at least three other accounts. This activity poses
reputational risk to organizations that engage with these accounts."
```

## 1. Key Findings

Present the most important findings in priority order. Use bullet points for clarity.

```
KEY FINDINGS
------------

- [Most significant finding with confidence level]

- [Second most significant finding with confidence level]

- [Third most significant finding with confidence level]

- [Additional findings as needed]

Note: Each finding should be a complete statement that can stand alone.
Include confidence language (almost certainly, likely, possibly, etc.)
```

---

## 2. Background

Provide context necessary to understand the analysis.

```
BACKGROUND
----------

Purpose of Investigation:
[State why this investigation was initiated and what questions it seeks to answer]

Scope:
[Define the boundaries of the investigation - time period, geographic focus,
platforms examined, etc.]

Previous Reporting:
[Reference any prior reports or ongoing analysis related to this subject]

Context:
[Provide relevant background information the reader needs to understand
the significance of the findings]
```

---

## 3. Analysis

Present detailed analysis supporting the key findings.

```
ANALYSIS
--------

[Finding 1 Header]
------------------

[Detailed explanation of the first key finding. Include:
- Evidence supporting the finding
- How the evidence was obtained
- Reasoning connecting evidence to conclusion
- Alternative explanations considered and why they were rejected]

Source: [Cite specific sources]
Confidence: [State confidence level and rationale]

[Finding 2 Header]
------------------

[Continue pattern for each major finding]

Analytic Judgments vs. Facts:
- Facts are presented as definitive statements with source citations
- Judgments are clearly marked with confidence language
- Assumptions underlying judgments are stated explicitly
```

---

## 4. Sources

Document all sources used in the analysis.

```
SOURCES
-------

Primary Sources:
1. [Source description] - [Date accessed] - [Reliability assessment]
2. [Source description] - [Date accessed] - [Reliability assessment]

Secondary Sources:
1. [Source description] - [Date accessed] - [Reliability assessment]

Source Reliability Assessment:
- A: Completely reliable
- B: Usually reliable
- C: Fairly reliable
- D: Not usually reliable
- E: Unreliable
- F: Cannot be judged

Information Validity Assessment:
- 1: Confirmed by other sources
- 2: Probably true
- 3: Possibly true
- 4: Doubtful
- 5: Improbable
- 6: Cannot be judged

Example: "B2" = Usually reliable source, information probably true
```

---

## 5. Confidence Assessment

```
CONFIDENCE ASSESSMENT
---------------------

Overall Confidence: [HIGH / MODERATE / LOW]

Factors Supporting Confidence:
- [Factor 1: e.g., Multiple independent sources corroborate findings]
- [Factor 2: e.g., Direct evidence from primary sources]
- [Factor 3: e.g., Consistent with established patterns]

Factors Limiting Confidence:
- [Limitation 1: e.g., Limited time period of observation]
- [Limitation 2: e.g., Possible deception or operational security by subject]
- [Limitation 3: e.g., Information gaps in specific areas]

Intelligence Gaps:
- [Gap 1: Information that would strengthen analysis if available]
- [Gap 2: Areas requiring further investigation]
```

IMPLICATIONS
------------

[Describe what the findings mean for the requestor/stakeholder]

Near-term implications:
- [Implication 1]
- [Implication 2]

Long-term implications:

## Classification/Sensitivity Markings for OSINT

While OSINT does not use government classification systems, sensitivity markings help recipients understand handling requirements.

```
OSINT SENSITIVITY LEVELS
------------------------

OSINT-UNRESTRICTED
- Publicly available information
- No restrictions on distribution
- May be shared externally

OSINT-SENSITIVE
- Contains personal information or sensitive analysis
- Internal distribution only
- Do not share externally without authorization

OSINT-RESTRICTED
- Contains information that could identify sources or methods
- Limited distribution on need-to-know basis
- Requires explicit authorization for sharing

HANDLING CAVEATS
----------------
- NOFORN equivalent: "DO NOT SHARE EXTERNALLY"
- LIMDIS equivalent: "LIMITED DISTRIBUTION - [specify recipients]"
- ORCON equivalent: "ORIGINATOR CONTROLLED - contact [name] before sharing"
```

## Template Checklist

Before finalizing your report, verify:

- [ ] BLUF clearly states the key finding in 2-4 sentences
- [ ] Key findings are listed in priority order with confidence levels
- [ ] Background provides sufficient context for understanding
- [ ] Analysis clearly separates facts from judgments
- [ ] All sources are documented with reliability assessments
- [ ] Confidence assessment addresses both supporting and limiting factors
- [ ] Sensitivity markings are appropriate
- [ ] Report answers the original intelligence requirement

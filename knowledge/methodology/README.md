## Quick Reference

### Intelligence Cycle Phases

1. **Direction/Planning** - Define requirements, allocate resources
2. **Collection** - Gather information from OSINT sources
3. **Processing** - Convert raw data to usable format
4. **Analysis** - Evaluate, integrate, interpret
5. **Dissemination** - Deliver finished intelligence
6. **Feedback** - Evaluate and improve

### Key Frameworks

- **PIRs/IRs**: Priority and Information Requirements for structured collection
- **Admiralty System**: Source reliability (A-F) and information credibility (1-6) ratings
- **ACH**: Analysis of Competing Hypotheses for systematic evaluation
- **SATs**: Structured Analytic Techniques for rigorous analysis

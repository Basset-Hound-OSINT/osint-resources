## Technique Categories

### Collection Techniques
- Search engine optimization for research
- Social media monitoring and archiving
- Public records access and aggregation
- Dark web and Tor research

### Analysis Techniques
- Timeline reconstruction
- Network mapping (social, organizational)
- Geolocation verification
- Image and video analysis

### Verification Techniques
- Multi-source corroboration
- Reverse image search workflows
- Metadata extraction and analysis
- Source triangulation

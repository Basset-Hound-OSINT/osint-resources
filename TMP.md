## PDF Indexer Script

### Location
`/home/devel/system_docs/scripts/osint_pdf_indexer.py`

### Usage
```bash
# Generate index with defaults
python3 ~/system_docs/scripts/osint_pdf_indexer.py

# Custom output location
python3 ~/system_docs/scripts/osint_pdf_indexer.py --output ./custom-index.md

# Dry run (print to stdout)
python3 ~/system_docs/scripts/osint_pdf_indexer.py --dry-run
```

### How It Works
1. Scans `~/osint-resources/pdfs/` directory
2. Extracts PDF filenames
3. Generates markdown with relative links
4. Outputs to `./knowledge/references/pdf-library-index.md`

### Future Enhancements

- Categorize PDFs by topic automatically

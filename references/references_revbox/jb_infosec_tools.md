Reverse Engineering Tools¶
A curated list of useful tools and resources for reverse engineering.

File / Binary Enumeration¶
[Strings] - Default “strings” tool to get readable strings from binaries and files
Flare Floss - The FLARE Obfuscated String Solver (FLOSS, formerly FireEye Labs Obfuscated String Solver) uses advanced static analysis techniques to automatically deobfuscate strings from malware binaries.
PEMonitor - Spot artifacts of executable files in order to ease and accelerate Malware Initial Assessment.
Foremost - Recover files based on their headers, footers, and internal data structures.
Proces Analyzers¶
SysInternals Process Monitor - Process Monitor is an advanced monitoring tool for Windows that shows real-time file system, Registry and process/thread activity.
API Monitor - API Monitor is a free software that lets you monitor and control API calls made by applications and services.
CMD Watcher - Watches for the CMD, PowerShell and other processes, suspends it, extracts the command line data, then optionally kills it.
IONinja - IO Ninja is a professional all-in-one terminal emulator, sniffer, and protocol analyzer.
Reverse Engineering Suites¶
GHidra - A software reverse engineering (SRE) suite of tools developed by NSA’s Research Directorate in support of the Cybersecurity mission
Cutter - Another reverse engineering tool.
Online analysis / Emulation / Sandboxing¶
Game hacking - Learn how to do some basic game hacking.
Hybrid Analysis - A free malware analysis service for the community that detects and analyzes unknown threats using a unique Hybrid Analysis technology.
Offline analysis / Emulation / Sandboxing¶
SpeakEasy - Speakeasy is a portable, modular, binary emulator designed to emulate Windows kernel and user mode malware.
.NET Decompilers¶
ILSpy - ILSpy is a .NET assembly browser and decompiler.
dnSpy - dnSpy is a debugger and .NET assembly editor

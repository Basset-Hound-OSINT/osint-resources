The following is a comprehensive list of tools and resources mentioned in the documentation that are directly related to scripting, automation, or provide scripting/API platforms for reverse engineering tasks.

### Scripting & Automation Tools

*   [IDA Python Src](https://github.com/idapython/src)
*   [sark (tmr232/sark)](https://github.com/tmr232/sark) (IDAPython Made Easy)
*   [docker-ida (intezer/docker-ida)](https://github.com/intezer/docker-ida) (For automating, scaling and distributing the use of IDAPython scripts)
*   [pytest-idapro (nirizr/pytest-idapro)](https://github.com/nirizr/pytest-idapro) (Record and Replay IDAPython API)
*   [idascript (devttys0/idascript)](https://github.com/devttys0/idascript) (Wrapper to automate the execution of IDA scripts from the command line)
*   [idapython-cheatsheet (inforion/idapython-cheatsheet)](https://github.com/inforion/idapython-cheatsheet) (Scripts and cheatsheets for IDAPython)
*   [flare-emu (fireeye/flare-emu)](https://github.com/fireeye/flare-emu) (Flexible interface for scripting emulation tasks)
*   [ida-minsc (arizvisa/ida-minsc)](https://github.com/arizvisa/ida-minsc) (Assists with scripting the IDAPython plugin)
*   [idapyhelper (patois/idapyhelper)](https://github.com/patois/idapyhelper) (Helps writing IDAPython scripts and plugins)
*   [ida-qscripts (0xeb/ida-qscripts)](https://github.com/0xeb/ida-qscripts) (IDA plugin to increase productivity when developing scripts for IDA)
*   [ida-climacros (0xeb/ida-climacros)](https://github.com/0xeb/ida-climacros) (Create and use macros in IDA's CLIs)
*   [ida-cmake (zyantific/ida-cmake)](https://github.com/zyantific/ida-cmake) (IDA plugin CMake build-script)
*   [idasix (nirizr/idasix)](https://github.com/nirizr/idasix) (IDAPython compatibility library)
*   [ida_vs2017 (patois/ida_vs2017)](https://github.com/patois/ida_vs2017) (IDA 7.x VisualStudio 2017 Sample Project for IDA and HexRays plugins)
*   [ida-pro-plugin-wizard-for-vs2013 (nihilus/ida-pro-plugin-wizard-for-vs2013)](https://github.com/nihilus/ida-pro-plugin-wizard-for-vs2013)
*   [idajava (cblichmann/idajava)](https://github.com/cblichmann/idajava) (Java integration for Hex-Rays IDA Pro)
*   [idaperl (nlitsme/idaperl)](https://github.com/nlitsme/idaperl) (Perl scripting support for IDApro)
*   [IDA Srvr (dzzie/re_plugins)](https://github.com/dzzie/re_plugins) (WM_COPYDATA IPC server running in IDA)
*   [IDA_JScript (dzzie/re_plugins)](https://github.com/dzzie/re_plugins) (Script IDA in Javascript)
*   [PyIDAServer (dzzie/re_plugins)](https://github.com/dzzie/re_plugins) (Python based IPC server running in IDA)
*   [x64dbgpy (x64dbg/x64dbgpy)](https://github.com/x64dbg/x64dbgpy) (Automating x64dbg using Python)
*   [advancedscript (ahmadmansoor/advancedscript)](https://github.com/ahmadmansoor/advancedscript) (Add More Features for x64dbg Script System)
*   [x64dbg_script_editor (techbliss/x64dbg_script_editor)](https://github.com/techbliss/x64dbg_script_editor)
*   [odbgscript (epsylon3/odbgscript)](https://github.com/epsylon3/odbgscript) (OllyDBG Script Engine)
*   [windbglib (corelan/windbglib)](https://github.com/corelan/windbglib) (Wrapper around pykd.pyd for Windbg, used by mona.py)
*   [windbg-scripts (0vercl0k/windbg-scripts)](https://github.com/0vercl0k/windbg-scripts) (JavaScript extensions for WinDbg)
*   [windbg_js_scripts (hugsy/windbg_js_scripts)](https://github.com/hugsy/windbg_js_scripts)
*   [pykd (windbgscripts/pykd)](https://github.com/windbgscripts/pykd) (Helpful PYKD scripts for Windbg)
*   [pefile Python Library](https://github.com/erocarrera/pefile)
*   [Ghidra (NationalSecurityAgency/ghidra)](https://github.com/NationalSecurityAgency/ghidra) (A reverse engineering suite supporting scripting)
*   [re-scripts (enovella/re-scripts)](https://github.com/enovella/re-scripts) (IDA, Ghidra and Radare2 scripts)
*   [Radare2 (radareorg/radare2)](https://github.com/radareorg/radare2) (Unix-like reverse engineering framework and commandline tools, designed for scripting)
*   [r2pipe (radareorg/radare2-r2pipe)](https://github.com/radareorg/radare2-r2pipe) (Access radare2 via pipe from any programming language)
*   [Frida](https://github.com/frida/frida) (Dynamic Binary Instrumentation framework used for dynamic scripting and instrumentation)
*   [frapl (friedappleteam/frapl)](https://github.com/friedappleteam/frapl) (Reverse engineering framework created to simplify dynamic instrumentation with Frida, including IDA plugins and Frida scripts)
*   [frida_for_ida_pro (techbliss/frida_for_ida_pro)](https://github.com/techbliss/frida_for_ida_pro) (Plugin for IDA Pro that uses the Frida API)
*   [PyREBox (Cisco-Talos/pyrebox)](https://github.com/Cisco-Talos/pyrebox) (Python scriptable Reverse Engineering sandbox)
*   [Unicorn CPU emulator framework](https://github.com/unicorn-engine/unicorn) (Often integrated into analysis tools for scripted emulation)
*   [angr (angr/angr)](https://github.com/angr/angr) (A powerful and user-friendly binary analysis platform, used extensively for symbolic execution and scripting)
*   [Manticore (trailofbits/manticore)](https://github.com/trailofbits/manticore) (Prototyping tool for dynamic binary analysis, with support for symbolic execution, taint analysis, and binary instrumentation)
*   [Qiling Framework](https://github.com/qilingframework/qiling) (Advanced binary emulation framework)
*   [parcelgen (yelp/parcelgen)](https://github.com/yelp/parcelgen) (Helpful tool to make data objects easier for Android)
*   [adb_helper_qt_super_version (techbliss/adb_helper_qt_super_version)](https://github.com/techbliss/adb_helper_qt_super_version) (All You Need For Ida Pro And Android Debugging)
*   [jemini (jbevain/cecil)](https://github.com/jbevain/cecil) (Library to inspect, modify and create .NET programs and libraries, useful for .NET automation)
*   [Fiddler](https://github.com/Fiddler/Fiddler) (Network analysis tool with a "Request to Code plugin" for generating code that executes requests)
*   [IDA Pro](https://github.com/idapro/ida) (IDA Pro contains a built-in command language, IDC, for scripting)
*   [peepdf](https://github.com/jesparza/peepdf) (PDF analysis and exploitation, includes scripting capabilities)
*   [jebscripts (enovella/jebscripts)](https://github.com/enovella/jebscripts) (A set of JEB Python/Java scripts for reverse engineering Android obfuscated code)
*   [Process Hacker (processhacker/processhacker)](https://github.com/processhacker/processhacker) (Multi-purpose tool for monitoring and debugging, often leveraged in automation)
*   [r2frida (nowsecure/r2frida)](https://github.com/nowsecure/r2frida) (Radare2 and Frida integration)
*   [ida_android_script (thecjw/ida_android_script)](https://github.com/thecjw/ida_android_script) (IDAPython scripts for Android debugging)
*   [reverse-engineering-arsenal (vallejocc/reverse-engineering-arsenal)](https://github.com/vallejocc/reverse-engineering-arsenal) (Useful Scripts for helping in reverse engeenering, including WinDbg and IDA scripts)
